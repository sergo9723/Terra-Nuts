# Terra Nuts — сайт, учёт остатков и Telegram-боты

Сайт-витрина с живыми остатками + два Telegram-бота (для клиентов и для вас
как админа) для приёма заказов, подтверждения и автоматического списания
товара. Все деньги и остатки считает обычный код с базой данных — никакого
непредсказуемого ИИ-агента в ядре системы нет (см. «Почему не ИИ-агент» ниже).

## Что нужно установить один раз

- [Node.js](https://nodejs.org/) 18 или новее (у вас уже стоит 22 — подходит).
- Аккаунт в Telegram (с телефона, на котором вы обычно сидите в Telegram) —
  через него будем создавать ботов.

## 1. Установка проекта

```bash
npm install
cp .env.example .env
npm run seed   # создаст базу data/terranuts.db и 10 товаров с примерными ценами
```

## 2. Создание двух Telegram-ботов

Заходите в Telegram, находите **@BotFather**, отправляете:

1. `/newbot` → он спросит имя (любое, например «Terra Nuts Заказы») → затем
   **username** — обязательно заканчивается на `bot`, например `TerraNutsOrderBot`.
   В ответ пришлёт **токен** вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Это — **клиентский бот**. Вставьте токен в `.env` в `CUSTOMER_BOT_TOKEN`,
   а username (без `@`) — в `CUSTOMER_BOT_USERNAME`.
2. Повторите `/newbot` ещё раз — второй бот, например «Terra Nuts Admin»,
   username вроде `TerraNutsAdminBot`. Токен вставьте в `ADMIN_BOT_TOKEN`.

### Как узнать свой `ADMIN_CHAT_ID`

1. Запустите проект (см. шаг 3) — админ-бот включится.
2. Напишите вашему админ-боту `/start` в Telegram.
3. Откройте в браузере (замените токен на свой):
   `https://api.telegram.org/bot<ADMIN_BOT_TOKEN>/getUpdates`
4. Там будет `"chat":{"id": 123456789, ...}` — это число впишите в
   `ADMIN_CHAT_ID` в `.env`.
5. Перезапустите проект (`Ctrl+C`, затем `npm start` снова).

Пока `ADMIN_CHAT_ID` не задан — админ-бот отвечает только в чате, откуда пришла
команда, но новые заявки уведомлять некуда, так что этот шаг обязателен.

## 3. Запуск

```bash
npm start
```

Откройте `http://localhost:3000` — увидите сайт с 10 товарами и остатками.
Оба бота (если токены заполнены) стартуют автоматически в том же процессе.

Чтобы сайт и боты продолжали работать, ноутбук должен быть включён и не уходить
в сон. Проще всего оставлять терминал с `npm start` открытым; когда бизнес
подрастёт — переезжаем на постоянный сервер (см. «Что дальше» внизу).

## 4. Как проверить, что всё работает

1. Откройте клиентского бота в Telegram, `/start` → выберите товар → пройдите
   до конца (количество → имя → телефон → адрес → подтвердить).
2. В админ-боте должно прийти уведомление с кнопками «Подтвердить» / «Отклонить».
3. Нажмите «Подтвердить» — клиент получит сообщение о подтверждении, а на сайте
   (обновите страницу или подождите 15 секунд) остаток уменьшится.
4. `/stock` в админ-боте — сверьте цифры с сайтом.

## 5. Себестоимость и цена

Стартовые цифры в `src/seed.js` — **примерные**, замените на свои через
админ-бота:

```
/setcost <id_товара> <сырьё_за_кг> <упаковка> <логистика> <маржа%>
```

`id_товара` смотрите в `/stock`. Например, себестоимость сырья 900 ₽/кг,
упаковка 45 ₽, логистика (доля доставки на одну пачку) 35 ₽, маржа 50%:

```
/setcost 1 900 45 35 50
```

Бот сразу пересчитает и покажет новую цену. Формула (файл `src/pricing.js`):

```
себестоимость = сырьё_за_кг × вес_г / 1000 + упаковка + логистика
цена = округление_вверх(себестоимость × (1 + маржа% / 100))
```

Подробный отчёт по всем товарам: `npm run pricing`.

### Фасовка (сколько грамм в упаковке)

Сейчас у каждого товара одна фасовка — 200 г (стандартная «подарочная»
порция для орехов и сухофруктов). Типичная розничная сетка, если захотите
добавить другие веса:

| Вес | Для чего |
|---|---|
| 100 г | пробник / подарок к заказу |
| 150–200 г | основной формат для крышки-герба (текущий) |
| 500 г | «семейная» упаковка, для постоянных клиентов |

Добавление второй фасовки на товар — небольшое расширение схемы БД
(`product_variants` уже поддерживает несколько строк на товар); скажите,
когда понадобится, и мы это включим.

## 6. Публикация сайта в интернет (пока без домена)

Пока домена нет — используем [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/)
(бесплатно, без пробрасывания портов на роутере):

```bash
# один раз установить (пример для Linux; для Mac — brew install cloudflared)
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o cloudflared
chmod +x cloudflared

# пока npm start работает в одном терминале, в другом:
./cloudflared tunnel --url http://localhost:3000
```

Появится случайный адрес вида `https://xxxx-xxx.trycloudflare.com` — это и
есть ваш публичный сайт для рекламы. Впишите его в `.env` в `SITE_URL` для
порядка (пока никуда не подставляется автоматически, просто для справки).
Когда купите домен — просто настроите его на тот же ноутбук тем же способом
или через постоянный туннель Cloudflare (без переустановки проекта).

Боты **не требуют** туннеля — они сами стучатся в Telegram, интернет нужен
только исходящий.

## 7. Продвижение (Instagram / Facebook / Telegram)

- **Instagram/Facebook пост**: квадрат **1080×1080** (лента) и **1080×1920**
  (сторис/Reels). На фото — товар в упаковке с гербом Terra Nuts + цена.
  В подписи — ссылка на сайт **или** сразу на клиентского бота
  (`https://t.me/<CUSTOMER_BOT_USERNAME>`). Кнопка в самой рекламе
  («Отправить сообщение» / «Перейти на сайт») — оба варианта заводятся на
  один и тот же клиентский бот, разница только в один или два клика.
- **Telegram-канал**: видео — процесс обжарки/упаковки, распаковка, доставка
  клиенту (соцдоказательство). 2–3 публикации в неделю достаточно для старта.
- Единая логика: **любой** канал рекламы в итоге ведёт в клиентского бота —
  туда, где реально оформляется и трекается заказ.

## Почему не ИИ-агент

Деньги и остатки товара должны считаться предсказуемо и проверяемо — свободный
ИИ-агент может ошибиться в арифметике или интерпретировать команду не так, как
нужно, а обнаружить это в реальном бизнесе с реальными деньгами сложно. Поэтому
приём заказов, списание остатков и расчёт цены — обычный код (этот проект).
Ключ Claude API можно позже использовать для необязательных, «мягких» задач —
например, автоответы на типовые вопросы покупателей в боте — но не для учёта.

## Что дальше (когда бизнес пойдёт)

1. Купить домен, настроить на тот же сервер (ноутбук или уже платный VPS).
2. Перенести `data/terranuts.db` на постоянный сервер (это просто файл —
   скопировать и запустить `npm start` там же).
3. При желании — добавить вторую фасовку на товар, онлайн-оплату картой,
   ИИ-ответы на частые вопросы в боте.

## Структура проекта

```
src/
  db.js               — схема SQLite
  seed.js             — стартовые 10 товаров
  pricing.js          — формула себестоимости/цены
  pricing-report.js   — npm run pricing — таблица по всем товарам
  queries.js          — вся работа с заказами/остатками
  routes/site.js       — страницы и API сайта
  bots/customerBot.js  — сценарий заказа для клиента
  bots/adminBot.js     — уведомления, /stock, /orders, /setcost
  server.js            — точка входа (сайт + оба бота)
views/index.ejs        — HTML витрины
public/                 — логотип, стили, статика
```
